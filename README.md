##   User Story

   - As a User, I want to be able to search for auto parts by name, so that i can
    find the part for my registered vehicle quickly and easily using the search 
    functionality in auto parts x.

   - As a User and Seller, I want to be able to list car parts that i want to sell,
    so that i can make money by selling my car parts to other users in auto parts x.

   - As a User, I want to be able to view the details of a car part, so that I can 
   make an informed decision before purchasing it in auto parts x.

   - As a User, i want to be able to see locations of sellers, so that I can find the
    nearest seller to me in auto parts x.
